# Mattestund

Räkneträning för låg- och mellanstadiet. Addition, subtraktion, multiplikation och division.

## Lägga upp på GitHub Pages

1. Skapa ett nytt repo på github.com (t.ex. `mattestund`), publikt.
2. Ladda upp innehållet i den här mappen (`index.html`, `support.js`, `manifest.webmanifest`, ikonerna).
3. I repot: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main / (root) → Save**.
4. Efter en minut finns adressen `https://<ditt-användarnamn>.github.io/mattestund/`.

## Lägga till på iPhone-hemskärmen

1. Öppna adressen i **Safari** (måste vara Safari, inte Chrome).
2. Tryck på dela-ikonen längst ner.
3. Välj **Lägg till på hemskärmen**.
4. Namnet är redan ifyllt: Mattestund. Tryck **Lägg till**.

Appen startar då i helskärm utan adressrad. Statistiken sparas lokalt på telefonen.
